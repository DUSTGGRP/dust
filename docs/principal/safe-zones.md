# 💜 SAFE ZONES

* <mark style="color:$success;">Restaurantes</mark>
* <mark style="color:$success;">Praça</mark>
* <mark style="color:$success;">Hospitais</mark>
* <mark style="color:$success;">Mecânicas</mark>
* <mark style="color:$success;">Eventos (Prefeitura)</mark>
* <mark style="color:$success;">Escola</mark>
* <mark style="color:$success;">Concessionária</mark>&#x20;
* <mark style="color:$success;">Júridico</mark>
* <mark style="color:$success;">Bombeiros</mark>



É proibido iniciar ou levar ações para dentro dessas áreas, situações onde envolvam **FUGA** ou qualquer meio de rota para despistar, deve ser evitado esses locais com extrema importância, qualquer abuso dessas áreas pode levar a punição administrativa.
